flare●
发现插件开发与发布连接 App

JavaScript / TypeScript SDK

开发取数逻辑，展示交给 flare。

可以先实现搜索和阅读，再逐步加入推荐、播放、评论或登录。插件独立更新，用户无需重新安装 App。

从模板开始

npm run plugin -- new author.source plugins/source
npm run plugin -- dev plugins/source
npm run plugin -- keygen
npm run plugin -- pack plugins/source

提交与发布

第一版由目录管理员核实发布者身份并登记公钥。将插件包、配套签名 JSON、内容分类与版本说明交给管理员；作者私钥始终由开发者自行保管。

发布端校验包结构、SDK、身份、签名和递增版本，通过后写入签名目录。目录审核不代表运行行为保证，用户安装时仍需确认访问权限。

目录接口

下载签名目录。客户端必须使用预先信任的目录公钥验签，不能自动信任下载包内的密钥。

插件由各自作者维护。安装前请核对来源与权限；网站不收集平台登录凭据。
