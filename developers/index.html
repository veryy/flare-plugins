从模板开始

安装 Node.js 22 或更新版本，将开发包解压后进入 flare-developer-kit 目录。

npm ci
npm run check
npm run plugin -- new author.source plugins/source
npm run plugin -- dev plugins/source
npm run plugin -- keygen
npm run plugin -- pack plugins/source

TypeScript 为默认语言；创建模板时添加 --language js 可改用 JavaScript。空搜索是开发占位，需要开发者实现真实取数；完整步骤见开发包中的 README。

提交与发布

提交插件或问题反馈

第一版由目录管理员核实发布者身份并登记公钥。将插件包、配套签名 JSON、作者公钥、内容分类与版本说明交给管理员；作者私钥始终由开发者自行保管。提交不会自动发布，也不要在问题反馈中附带账号、Cookie 或临时媒体签名。

发布端校验包结构、SDK、身份、签名和递增版本，通过后写入签名目录。每个插件详情展示历史版本和下载摘要，用户安装时仍需确认访问权限。

目录接口

下载完整签名目录，旧版 App 兼容目录。客户端必须使用预先信任的目录公钥验签，不能自动信任下载包内的密钥。

插件由各自作者维护。安装前请核对来源与权限；网站不收集平台登录凭据。
