使用说明

# 知乎日报

此插件读取知乎日报的公开接口，提供最新文章、按日期浏览往期、结构化正文和图片。内容发布者显示为知乎日报，实际作者署名保留在正文中；内容版权归原作者与平台。

这是日报阅读插件，不是完整知乎适配：不提供问题／回答搜索、账号登录或平台互动。不要求登录；平台拒绝访问、内容移除或结构不支持时显示实际错误，不返回演示内容。

正文通过随包构建的 parse5 解析为文本、标题、引用和图片，丢弃脚本、样式、嵌入网页、表单和非声明图片域名。主 App 负责渲染，不执行文章的 JS 或 CSS。依赖许可及上游参考见 NOTICE。

参考 Zhihu++ 的日报接口声明；没有复制或翻译其客户端实现。平台与 Android 实测边界见项目 docs/platform-adapters.md。

从文件导入

下载所需版本的插件包、作者签名，以及下面的作者公钥。在 flare 的「我的 → 管理插件 → 从文件导入插件」依次选择三个文件，核对作者公开的公钥指纹，再确认能力与访问权限。
