使用说明

# 知乎实验插件

独立 TS 实现，参考知乎++的接口和字段事实，源码为 0BSD；不包含其 AGPL 实现、签名算法或平台响应语料。依赖及来源见 NOTICE。

支持问题／回答／文章分享链接、热榜、搜索排序和回答／文章筛选、问题回答目录独立分页、结构化正文及图片、作者资料与作品分页、评论与回复，以及官方网页登录和账号状态查询。问题用稳定 `question:<id>` 集合引用，回答目录走 `getCollectionItems`，分页不是虚构的新内容 ID。原始 64 位十进制 ID 在 JSON 解析前保留为字符串；游标绑定当前账号、问题／作者／评论或搜索条件。

当前直接匿名公网探测的回答、文章、热榜和搜索分别返回 403／403／401／403。拒绝访问、登录要求、未知登录状态、仅预览或付费正文均明确报错，不返回假空结果。此版不证明真实账号成功登录或读取。平台账号在 flare 插件中心添加，登录页为 `https://www.zhihu.com/signin`；完成窗口后再查 `/api/v4/me`，仅关闭窗口不算登录成功。请求仅通过宿主的本插件当前账号会话，不包含 Cookie、口令、令牌或自动刷新凭据。

不提供平台点赞、收藏、关注或发表评论；不声明短链、想法或视频支持。正文不执行原网页脚本。平台访问条件变化需要单独实测，不能用合成测试替代公网验收。

需要支持 `getCollectionItems` 的新版 App。官方兼容目录不会向旧 App 提供此包；完整目录保留版本和签名。

从文件导入

下载所需版本的插件包、作者签名，以及下面的作者公钥。在 flare 的「我的 → 管理插件 → 从文件导入插件」依次选择三个文件，核对作者公开的公钥指纹，再确认能力与访问权限。
