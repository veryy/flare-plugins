使用说明

# 从模板开始

这是公开 SDK 开发教程，只提供本地文章，不访问平台、登录或网络。搜索 hello，打开「从模板到 flare」并存到 flare；插件更新后，用原收藏继续打开。

在独立开发包中先执行 `npm run plugin -- new flare.developer-guide plugins/guide`，再用本教程的清单和 TypeScript 源码替换模板。执行 `npm run check`、`npm run plugin -- preview plugins/guide --method search --args '{"query":"hello"}'`，并用 `npm run plugin -- dev plugins/guide` 在本机工作台调试。打包使用 `npm run plugin -- pack plugins/guide`。

发布自己的插件时，把清单 ID／作者和源码引用中的 flare 命名空间改为自己的身份，用自己的私钥签名，并按网站的提交入口交管理员审核。作者私钥不上传。发布 1.1.0 时，同时修改清单版本与源码 release，保持内容 ID 和 route 不变。

下面附有本版本完整清单和源码，可在公开开发包中复现；较新的开发包也在 recipes/first-plugin 提供相同基础教程。只有搜索与阅读能力，不支持首页推荐，这是允许的最小插件。

## 本版本源码

```ts
import { definePlugin, PluginError } from '@flare/sdk';

const release = '1.1.0';
const ref = { pluginId: 'flare.developer-guide', id: 'hello', type: 'article' as const, context: { route: 'guide-v1' } };
const summary = { ref, title: '从模板到 flare', author: { id: 'flare', name: 'flare 示例作者' }, excerpt: '搜索 hello，阅读并收藏，再通过网站独立更新插件。' };

export default definePlugin({
  getCapabilities() { return { methods: ['getCapabilities', 'search', 'getDetail'] }; },
  async search({ query, cursor }, host) {
    host.log('info', '教程搜索');
    return { items: !cursor && (query.toLowerCase().includes('hello') || summary.title.includes(query)) ? [summary] : [], nextCursor: null };
  },
  async getDetail(value) {
    if (value.pluginId !== ref.pluginId || value.id !== ref.id || value.type !== ref.type || value.context?.route !== ref.context.route) {
      throw new PluginError('NOT_FOUND', '教程文章引用无效');
    }
    return { ...summary, blocks: [
      { type: 'heading', level: 1, text: '从模板到 flare' },
      { type: 'text', text: `教程插件版本 ${release}` },
      { type: 'text', text: '内容来自独立 JS 插件；页面、搜索与本机收藏由 flare 提供。' },
    ] };
  },
});

```

从文件导入

下载所需版本的插件包、作者签名，以及下面的作者公钥。在 flare 的「我的 → 管理插件 → 从文件导入插件」依次选择三个文件，核对作者公开的公钥指纹，再确认能力与访问权限。
