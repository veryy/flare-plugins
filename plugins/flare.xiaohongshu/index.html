使用说明

# 小红书实验插件

独立 TypeScript／JavaScript 插件，通过宿主受控 WebView 读取小红书网页实际加载的数据。主 App 不包含小红书取数逻辑。支持网页推荐、默认搜索、完整笔记链接、结构化文字／顺序图片、视频播放资源与官方网页登录；不声明作者页、评论或平台写入。

`1.0.2` 的推荐／搜索使用可选 `web.readPage`／`web.closePage`，需要 flare `v0.1.84.0` 或更新版本。续页沿用同一真实网页，保留已观察到的内容顺序和滚动位置，不再重新加载随机推荐。旧宿主缺少此扩展时明确要求更新 App；详情和账号检查仍使用独立的单次网页读取。SDK 仍为版本 1，安装成功本身不代表宿主具备所有可选扩展。

`1.0.1` 使用带尾斜杠的 HTTPS 搜索入口 `/search_result/`。当前无尾斜杠入口会 301 跳转至 HTTP，宿主按权限规则阻止该跳转；修复为直接访问正确的 HTTPS 地址，未放宽协议、域名或账号权限。读取和登录均明确选择 `viewMode: 'desktop'`，使用对应的桌面网页数据结构；此选项需要新版 flare，旧宿主可能继续收到移动落地页，此时明确返回不支持。页面仍需实际提供内容，正确入口和桌面布局本身不等于已经获得平台访问权限。

部分平台 CDN 地址仍使用旧的 HTTP 表示。插件保留原路径及参数，映射为同一已声明 CDN 的 HTTPS 地址；不向 HTTP 发请求，也没有 HTTPS 失败后回退 HTTP 的路径。未知域名、内嵌账号密码与非标准端口继续拒绝。

每次调用使用宿主的插件／账号隔离环境，网络与凭据由宿主管理。只投影当前笔记、列表或已验证账号的必要字段，不导出整个网页状态、Cookie、登录二维码或验证码。没有平台签名实现、自动验证、请求伪装或访问限制绕过。需设备 WebView 支持独立配置环境。

推荐和搜索按当前网页顺序分页：游标绑定网页会话、推荐／搜索词和账号，宿主同时核对插件包、入口及显示模式。保留已观察的内容标识后，平台列表替换已加载卡片也不丢失上页位置；每个新游标单独计时，读取较久后继续翻页不会沿用首屏的等待超时。每页最多 20 条，每个网页最多观察 1000 条；只有页面明确表示结束才返回结束游标。读完或出错主动关闭网页，清理失败保留原访问错误，并由宿主时限回收。

宿主最多保留两个网页，空闲两分钟／总存活五分钟、环境变更或回收后会话失效，明确返回 `NOT_FOUND` 要求刷新；不会新开页面继续旧游标。`1.0.1` 及更早的旧格式游标也需刷新。空的初始状态、暂时没有新内容、超时或拒绝访问都不会当成“没有结果”。这不是跨重启／长期保存的分页保证；不要把网页会话游标当作收藏内容引用。

平台后续请求失败时，先返回已经观察到但尚未展示的卡片；这页仍保留后续游标，缓存耗尽后明确报告平台错误。不会丢弃已取到的卡片，也不会把失败改成“没有更多”。同页续读本身不代表平台允许持续加载，真实访问条件与限制需独立实测。

笔记 ID 与可能过期的定位参数、媒体地址分开；收藏保存稳定内容引用，播放时重新读取网页资源。支持 `https://www.xiaohongshu.com/explore/<id>`、`/search_result/<id>`、`/discovery/item/<id>` 完整链接，保留链接中的 `xsec_token` 内容定位参数；短链接与 rednote.com 国际站尚未支持。缺少／过期定位参数可能导致平台拒绝访问，请换用官方页面的完整链接。

登录窗口完成后再次查询实际网页账号状态；只有明确登录标志和有效账号资料才确认成功。关闭窗口不等于登录。匿名页面可能限制推荐／搜索，实际账号成功读取、真实视频解码与长期分页仍待验收。合成测试只验证协议和运行环境，不能证明平台当前允许访问。来源与许可说明见 NOTICE。

```sh
node tools/flare.mjs build plugins/xiaohongshu
node --test tools/tests/xiaohongshu.test.mjs
```
