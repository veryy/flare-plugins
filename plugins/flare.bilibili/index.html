使用说明

# B 站插件

独立 TS 插件，使用 B 站公开 Web 接口，提供热门流、视频搜索、简介、分 P 引用和按需播放解析。无演示数据回退；接口失败显示实际错误。主页热门流不是个性化推荐。

只选择平台实际返回的 AVC／AAC 资源，使用 HTTPS 默认端口的已声明 CDN；不修改平台签名、不解锁画质、不绕过付费或地区条件。分 P 引用保留稳定 CID，播放地址不写入收藏。

当前不支持登录、平台点赞收藏、短链接、番剧、直播和非第一页分享参数。内容可能因平台访问限制、地区、接口变更或设备编解码能力而不可用。原文可在 B 站打开。不同画质和分 P 的 UI 支持以主 App 为准。

公开接口实测与限制见 docs/platform-adapters.md。原生设备实测与公网分发尚需继续验证；Node 公网取数成功不等于 Android 播放已验收。

从文件导入

下载所需版本的插件包、作者签名，以及下面的作者公钥。在 flare 的「我的 → 管理插件 → 从文件导入插件」依次选择三个文件，核对作者公开的公钥指纹，再确认能力与访问权限。
