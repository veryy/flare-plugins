使用说明

# B 站插件

独立 TS 插件，使用 B 站公开 Web 接口，提供热门流、视频搜索、简介、分 P 引用、按需播放解析和只读评论／楼中楼。无演示数据回退；接口失败显示实际错误。主页热门流不是个性化推荐。

1.1.0 新增评论。打开视频详情的「查看评论与回复」，读取热门评论及楼中楼；不预取、不发表评论或对评论点赞。每次重新核对原视频的 AV 标识，主评论与各楼层分别分页，游标绑定视频及父评论，评论 ID 使用精确字符串。评论文字以纯文本展示，表情保留平台文本标记，不执行 HTML。未知点赞数保留为未知。权限与旧版相同，不需要账号、网页或存储权限。

平台可能只向匿名请求返回少量热门评论，或在后续页返回不可用的分页信息。这时明确报错并保留已加载内容，不显示成「暂无评论」或伪造完整列表。评论区关闭、平台拒绝、限流和数据错误也保留实际错误；不自动重试，不绕过访问条件。

只选择平台实际返回的 AVC／AAC 资源，使用 HTTPS 默认端口的已声明 CDN；不修改平台签名、不解锁画质、不绕过付费或地区条件。分 P 引用保留稳定 CID，播放地址不写入收藏。

1.2.0 新增实验性账号能力。确认新增的账号、网页和登录域名权限后，在插件管理中添加账号，使用 B 站自己的网页完成登录；关闭网页不代表登录成功，随后用当前账号会话查询平台状态。账号与 Cookie 由 App 按插件和本机账号隔离保存，插件不保存账号凭据或输出校验令牌。退出并移除只清理本机环境，不等于注销其他设备上的 B 站会话。

详情可查询原平台点赞／收藏／关注状态，明确设置点赞或取消点赞、关注或取消关注。先查询目标，已达到同一目标不再次写入；写入后再查平台确认，失败或超时不重发。点赞作用于整个 BV 视频，分 P 的 flare 本机收藏仍独立保存。关联作者上下文会核对原作品，不能把内容 ID 当作者 ID；不能关注自己或自动解除屏蔽。

1.3.0 增加目标收藏夹选择。需要支持 `getFavoriteFolders` 的新版 flare，旧 App 会明确拒绝不兼容清单；请先更新 App，再升级此插件。详情中的“管理原平台收藏夹”列出当前账号自己的收藏夹及此视频的归属，用户逐个添加或移出，保留其他收藏夹。目标来自当前账号与当前内容，每次写入前重新核对归属和成员状态，操作后按该收藏夹确认，不用总收藏状态代替。已满足目标时不重复写入；响应丢失后先重新查询，不自动重发。最多支持 500 个收藏夹，分页绑定账号、内容和当前收藏夹标识集合，列表变化时要求刷新。缺少归属或状态时禁用写入，不猜测默认收藏夹或清空所有收藏夹。

真实登录成功和平台实际写入需要用户在自己的账号上另行验收；受控响应或登录页加载不能代替这一步。平台要求的验证、拒绝或限流按实际结果处理，不绕过校验。

当前不支持新建／删除平台收藏夹、短链接、番剧、直播和非第一页分享参数。内容可能因平台访问限制、地区、接口变更或设备编解码能力而不可用。原文可在 B 站打开。不同画质和分 P 的 UI 支持以主 App 为准。

公开接口和实际设备验收范围见 App 仓库 docs/platform-adapters.md。旧版视频／正文的设备结果不替代新增评论的设备验证；Node 公网取数成功也不等于 Android 界面已验收。
